# Как получить APK без установки Flutter (через GitHub Actions)

APK соберётся в облаке GitHub, вам останется его скачать и поставить на телефон.
Файл будет в **демо-режиме** (встроенные данные, без Supabase) — то, что нужно,
чтобы «пощупать».

## Шаги

1. **Зарегистрируйтесь** на github.com (бесплатно).
2. Создайте новый репозиторий (кнопка **New**). Можно приватный.
3. **Загрузите проект** в репозиторий одним из способов:
   - Проще всего: на странице репозитория → **Add file → Upload files** →
     перетащите всё содержимое папки проекта (вместе со скрытой папкой
     `.github`). → **Commit**.
   - Или через Git/GitHub Desktop, если умеете.
4. Откройте вкладку **Actions**. Сборка «CI & Build APK» запустится сама
   (или нажмите **Run workflow**). Подождите ~5–10 минут.
5. **Если сборка зелёная (✓):** откройте её → внизу блок **Artifacts** →
   скачайте **komplekt-apk** (это zip) → распакуйте → внутри `app-debug.apk`.
6. **Перенесите APK на телефон** (через USB, Telegram «Избранное», Google Drive
   и т.п.). На телефоне откройте файл → разрешите **«Установка из неизвестных
   источников»** для этого приложения → установите.

## Если сборка красная (✗)

Это ожидаемо на первом запуске — код ещё ни разу не компилировался. Откройте
упавший шаг (обычно **Build debug APK** или **Analyze**), скопируйте текст
ошибок и пришлите мне — я внесу правки, вы зальёте обновление, и сборка
повторится автоматически.

## Примечания

- Сборка собирает **debug-APK** — он подписан отладочным ключом и ставится на
  любой Android без дополнительной настройки. Для публикации в Google Play нужен
  отдельный release-ключ (это уже в ROADMAP).
- iOS так собрать нельзя — для iPhone нужен Mac и аккаунт Apple Developer.
- Чтобы потом собрать «боевой» APK с реальной базой — впишите ключи Supabase в
  `.env` и поставьте `DEMO_MODE=false`.
