# Локальный запуск: Claude Code и проект на своём компьютере

Инструкция для чистой системы — например, после переустановки Windows.
Читай по порядку. Если где-то застрянешь, пришли скриншот или текст ошибки.

Зачем это нужно: в облачной сессии Claude Code нет доступа к твоей базе
Supabase и нет Flutter — сетевая политика пропускает только GitHub. На своём
компьютере таких ограничений нет: там и база, и сборка приложения, и запуск
на эмуляторе. Поэтому основную работу удобнее вести локально.

Идентификатор проекта Supabase: **`xncupkiiuhpcsficvnbr`**. Он не секретный —
виден в адресе API и внутри самого приложения. Ссылки ниже уже с ним.

---

## 1. Claude Code

**Шаг 1. Node.js.** Скачай с [nodejs.org](https://nodejs.org) версию LTS и
установи (все галочки по умолчанию). Проверь в терминале — на Windows это
PowerShell, найди его через поиск в меню «Пуск»:

```bash
node --version
```

Должна появиться версия, например `v22.14.0`.

**Шаг 2. Сам Claude Code:**

```bash
npm install -g @anthropic-ai/claude-code
```

**Шаг 3. Запуск и вход:**

```bash
claude
```

При первом запуске попросит войти в аккаунт Anthropic — откроется браузер.

> Способы установки со временем меняются. Если команда выше не сработала,
> актуальная инструкция — на [code.claude.com/docs](https://code.claude.com/docs).

## 2. Проект

**Git.** Скачай с [git-scm.com](https://git-scm.com) и установи.

**Клонирование.** В терминале перейди в папку, где хочешь держать проект
(например `cd C:\Projects`), и выполни:

```bash
git clone https://github.com/abelkz/-komplekt-app2.git
cd -komplekt-app2
```

В репозитории лежит файл `CLAUDE.md` — Claude Code прочитает его сам при
запуске в этой папке и сразу будет знать про проект: стек, архитектуру,
грабли. Изучать всё заново не придётся.

## 3. Ключи Supabase (файл `.env`)

**Этого файла нет в репозитории** — он в `.gitignore`, чтобы ключи не утекли
в открытый доступ. Поэтому после клонирования его нужно создать.

**Шаг 1.** Скопируй шаблон:

```bash
copy .env.example .env
```

(на macOS и Linux — `cp .env.example .env`)

**Шаг 2.** Возьми два значения из Supabase. Открой прямую ссылку:

**https://supabase.com/dashboard/project/xncupkiiuhpcsficvnbr/settings/api-keys**

Нужны:

| Что | Куда вписать |
|---|---|
| Project URL | `SUPABASE_URL=` |
| Ключ **anon** / **publishable** | `SUPABASE_ANON_KEY=` |

> В нынешнем дашборде раздел **Database** из бокового меню настроек убрали,
> а строки подключения спрятали за кнопкой **Connect** вверху страницы —
> если будешь искать по памяти, собьёшься. Пользуйся прямыми ссылками.

**Шаг 3.** Открой `.env` Блокнотом, впиши значения и убедись, что там стоит:

```
DEMO_MODE=false
```

Если оставить `true`, приложение запустится на встроенных тестовых данных,
без реальной базы — это удобно, чтобы просто посмотреть интерфейс.

Остальные строки (`DEFAULT_CITY`, координаты Астаны) уже заполнены.

## 4. Flutter — если нужно собирать и запускать приложение

Для работы с кодом через Claude Code это не обязательно: анализ и правки он
делает и без Flutter, а сборку проверяет CI на GitHub. Но чтобы **увидеть
приложение на эмуляторе**, Flutter нужен.

1. **Flutter SDK** — [docs.flutter.dev/get-started](https://docs.flutter.dev/get-started/install),
   распаковать в `C:\src\flutter`, добавить `C:\src\flutter\bin` в переменную
   среды `Path`.
2. **Android Studio** + Android SDK + эмулятор (Pixel, Android 14).
3. Проверить: `flutter doctor` — не должно быть красных крестов по Flutter
   и Android.

Затем в папке проекта:

```bash
flutter create .      # создаёт папки android/ ios/ web/ — их нет в git
flutter pub get
flutter run
```

`flutter create .` не трогает код в `lib/` — только добавляет платформенные
папки.

## 6. Если забыл пароль базы

Пароль базы нужен **не приложению**, а только прямому подключению к Postgres —
например, workflow миграций. Приложение ходит в базу по anon-ключу.

Сбросить можно здесь:

**https://supabase.com/dashboard/project/xncupkiiuhpcsficvnbr/settings/database**

Блок **Database password** → **Reset database password**. Новый пароль
показывается один раз — скопируй сразу.

Сброс безопасен для работающего приложения: оно паролем не пользуется.

## 7. Частые проблемы

**Приложение показывает бесконечную загрузку.** Скорее всего, проект Supabase
уснул — на бесплатном тарифе он встаёт на паузу после 7 дней без обращений.
Проверь на [странице проекта](https://supabase.com/dashboard/project/xncupkiiuhpcsficvnbr):
если написано *Paused* — нажми **Restore**. Чтобы это не повторялось, нужен
тариф Pro.

**`flutter doctor` ругается на Android licenses.** Выполни
`flutter doctor --android-licenses` и согласись со всем.

**Сборка падает сразу после `flutter pub get`.** Версии пакетов в проекте не
зафиксированы (`pubspec.lock` в `.gitignore`), поэтому подтягиваются свежие и
иногда ломающие. Пришли текст ошибки — поправим ограничение версии.

**Не помню, что вообще происходило в проекте.** Всё записано в `CLAUDE.md`,
раздел «Текущее состояние»: что сделано, что осталось, какие есть хвосты.
